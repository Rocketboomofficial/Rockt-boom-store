# Rocket Boom Store — PWA

## ساختار ریپو
فایل `index.html`، مانیفست و Service Worker مستقیماً در ریشه ریپو قرار می‌گیرند. فقط تصاویر و آیکون‌ها داخل `assets/` هستند.

## انتشار
1. تمام فایل‌های داخل ZIP را مستقیماً در ریشه ریپوی GitHub آپلود کن؛ پوشه والد ZIP را آپلود نکن.
2. در Settings → Pages، انتشار از branch اصلی و مسیر /(root) را فعال کن.
3. آدرس HTTPS منتشرشده را در https://www.pwabuilder.com وارد کن.
4. بخش Package و Android را انتخاب و مراحل ساخت را دنبال کن.

## افزودن اپلیکیشن یا بازی
در `index.html` آرایه `catalog` در انتهای فایل را پیدا کن. برای هر برنامه یک مورد با `name`, `maker`, `type`, `icon`, `detail`, `keywords` اضافه کن. مقدار `type` باید `apps` یا `games` باشد. برای اپ‌های تازه صفحه جزئیات و لینک دانلود اختصاصی بساز.

## نکته
امتیاز و نظر ساختگی در فروشگاه نمایش داده نمی‌شود. بخش‌های جستجو، دسته‌بندی، صفحه جزئیات، گالری، به‌زودی و تنظیمات فعال هستند.
