# Rocket Boom Store

فروشگاه موبایل‌محور اپلیکیشن‌ها و بازی‌ها، آماده انتشار روی GitHub Pages و تبدیل به PWA با PWABuilder.

## انتشار روی GitHub
1. محتویات این پوشه را در ریشه یک repository قرار بده.
2. در GitHub برو به Settings → Pages.
3. گزینه Deploy from a branch را انتخاب کن و branch اصلی و پوشه /(root) را فعال کن.
4. بعد از انتشار، آدرس سایت را در PWABuilder وارد کن.

## ساخت PWA با PWABuilder
- آدرس عمومی HTTPS سایت را در https://www.pwabuilder.com وارد کن.
- manifest.webmanifest و service-worker.js در ریشه پروژه قرار دارند.
- از بخش Package، خروجی Android را انتخاب و مراحل راهنمای PWABuilder را دنبال کن.

## شخصی‌سازی اپ‌های بیشتر
کارت‌های اپلیکیشن در index.html داخل بخش‌های `برنامه‌های پیشنهادی` و `بازی‌های پرطرفدار` قرار دارند. برای افزودن اپ جدید، یک کارت با آیکون، نام، سازنده، توضیح و لینک دانلود اضافه کن و برای آن صفحه جزئیات بساز.

## نکته
اطلاعات نسخه، امتیاز و سازنده فعلاً نمونه/قابل ویرایش هستند. پیش از انتشار عمومی، مشخصات واقعی هر اپ را جایگزین کن. برای آیکون PNG در خروجی‌های خاص فروشگاه، می‌توانی نسخه‌های 192×192 و 512×512 هم به assets اضافه کنی.
