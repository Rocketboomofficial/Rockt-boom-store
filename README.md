# Rocket Boom Store — PWABuilder

فایل‌های اصلی مستقیماً در ریشه ZIP قرار دارند؛ پوشه مادر وجود ندارد.
همه فایل‌ها را در ریشه ریپوی GitHub آپلود کن، GitHub Pages را از /(root) فعال کن
و آدرس HTTPS را در PWABuilder وارد کن.

برای آیکون جنگنده اصلی، لازم است فایل آیکون را از ریپوی بازی به من بدهی یا داخل
`assets/` با نام `rocket-boom-icon.png` قرار بدهی. این فایل در محیط فعلی در دسترس نبود،
پس آیکون اصلی را حدس نزدم.
