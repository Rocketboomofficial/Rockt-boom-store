# Rocket Boom Store — PWABuilder

تمام فایل‌های ZIP مستقیماً در ریشه ریپو قرار می‌گیرند؛ پوشه مادر وجود ندارد.
فایل‌ها را در ریشه ریپوی GitHub آپلود کن، GitHub Pages را از /(root) فعال کن
و آدرس HTTPS را در PWABuilder وارد کن.

برای آیکون دقیق جنگنده بازی، فایل آیکون اصلی را لازم دارم. آن را از ریپوی بازی
دانلود و به‌عنوان `assets/rocket-boom-icon.png` اضافه کن؛ آیکون اصلی در فایل‌های
در دسترس این گفتگو وجود ندارد و نمی‌خواهم تصویر اشتباهی جایگزین کنم.
